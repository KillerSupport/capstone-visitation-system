TO RUN THE PROJECT, OPEN TERMINAL THEN TYPE THIS: npm.cmd run dev

The project automatically keeps its npm cache and Node temporary files on D:.
Node/tsx temporary files use .local-backups\npm-temp.
npm uses the Windows NPM_CONFIG_CACHE setting, with .local-backups\npm-cache as the project fallback.

Restart VS Code after changing the Windows temporary-folder settings.

Run the command once. To restart, press Ctrl+C in that terminal first.
